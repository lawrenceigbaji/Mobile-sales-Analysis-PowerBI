# 📱 Mobile Sales Analysis Dashboard (Power BI)

## 📖 Project Overview

This project presents an interactive Mobile Sales Analysis Dashboard developed in Microsoft Power BI. The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPIs, and filters, enabling stakeholders to monitor sales performance and customer behavior.

---

# 🎯 Business Objectives

The objective of this project was to:

- Analyze overall mobile phone sales performance
- Monitor total revenue and units sold
- Evaluate customer demographics
- Compare payment methods
- Identify revenue trends across customer age groups
- Build an interactive dashboard for business decision-making

---

# 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Visualizations

---

# 📂 Dataset

The dataset contains mobile phone sales transactions including:

- Transaction ID
- Date
- Mobile Model
- Brand
- Price
- Units Sold
- Total Revenue
- Customer Age
- Customer Gender
- Payment Method

---

# 📊 Dashboard Features

### Executive Dashboard

The main dashboard provides:

- Total Revenue
- Total Units Sold
- Total Male Customers
- Total Female Customers
- Other Customer Categories
- Revenue by Payment Method
- Revenue by Customer Gender
- Interactive Payment Method Filter

---

### Customer Profile Analysis

Provides insight into:

- High-value customers
- Low-value customers
- Revenue contribution by customer profile

---

### Age Category Analysis

Analyzes revenue generated by:

- Youth
- Young Adults
- Elderly Customers

This helps businesses understand which customer age segment contributes the highest sales revenue.

---

# 📈 Key Business Insights

- Youth customers generated the highest revenue.
- Credit Card and Online payments contributed significantly to total sales.
- Customer demographics reveal differences in purchasing behavior.
- The dashboard enables fast filtering for better business decisions.
